# 常见错误案例及修正方案

## 1. 想定格式错误
- **错误表现**：想定缺少必要字段，或字段格式不正确
- **影响**：无法进行有效的评估和仿真
- **修正方案**：根据scenario_schema.md检查并补全必要字段

## 2. 逻辑矛盾
- **错误表现**：想定中存在逻辑不一致的情况，如时间线冲突、资源分配矛盾
- **影响**：仿真结果不可靠，可能导致仿真崩溃
- **修正方案**：重新梳理想定逻辑，确保时间线和资源分配的一致性

## 3. 参数范围错误
- **错误表现**：想定中的参数值超出合理范围，如部队数量过多或过少
- **影响**：仿真结果不真实，不符合实际情况
- **修正方案**：参考领域知识和历史数据，调整参数值到合理范围

## 4. 缺少关键信息
- **错误表现**：想定中缺少关键的背景信息或约束条件
- **影响**：仿真过程中可能出现无法处理的情况
- **修正方案**：补充必要的背景信息和约束条件，确保仿真过程的完整性

## 5. 与历史数据不符
- **错误表现**：想定中的设定与已知的历史数据或现实情况不符
- **影响**：仿真结果缺乏可信度
- **修正方案**：参考历史数据和现实情况，调整想定设定
